# scripts

Build, run and test scripts of the PSP port. The EBOOT built by `build-psp-ikaruga.sh` runs Ikaruga in
PPSSPP through chapter 1 at ≈0.086x of real time (≈5 fps) without audio; the tests below run it in
PPSSPP, one PPSSPP at a time. Image tests compare only against Flycast (`capturar-flycast.sh`,
`comparar-flycast.sh`); the recompiled PC launcher is used only by the `test-psp-igual-pc*.sh` hash
oracle. All the PPSSPP tests need `PROBAR_DISCO` (the real disc's HD area, `docs/primer-uso.md`). Index of
the docs: `docs/README.md`.

- `build-psp.sh [--limpio]`: builds `psp/hola` into `build/psp/hola/EBOOT.PBP` inside Docker with PSPDEV v20261001 pinned by sha256 (`scripts/psp/Dockerfile`); `--limpio` drops the toolchain image and rebuilds without cache. Needs: Docker.
- `probar-ppsspp.sh <EBOOT.PBP> <captura.png>`: boots the EBOOT in PPSSPP (flatpak `org.ppsspp.PPSSPP`) on Xvfb, saves a screenshot, exits non-zero if the boot fails. Needs: flatpak, xvfb-run, ImageMagick.
- `test-psp-hola.sh [--sin-limpio]`: acceptance test: clean build, OCR reads "ikaruga-psp" in the capture, a truncated EBOOT is rejected. Needs, besides the above: tesseract.

- `build-psp-ikaruga.sh <dir-gen> [--variantes=mix[,Os,O2]] [--solo-o2] [--limpio]`: compiles dream-recomp's core (submodule + `patches/dream-recomp/*.patch` on a copy), the translated C++ in `<dir-gen>` (mounted read-only, never copied) and `psp/stubs` with psp-g++, one directory per variant: `mix` (runtime and stubs `OPT_RT=-O2`, generated `OPT_GEN=-Os`; default, `build/psp/ikaruga/ikaruga.elf` and `EBOOT.PBP`), `Os` (all -Os; `ikaruga-Os.elf`, `EBOOT-Os.PBP`), `O2` (all -O2; `ikaruga-O2.elf`, no EBOOT). Default `--variantes=mix`. `OPT_RT`/`OPT_GEN` in the environment override the `mix` flags. EBOOTs use MEMSIZE=1; prints `psp-size` against ~52 MB. Needs: Docker, `git submodule update --init third_party/dream-recomp`.
- `scripts/psp/tamano-por-grupo.py <map>`: bytes of the linked image per origin (generated code, runtime, libstdc++, newlib...) from the ld map.
- `preparar-disco-ikaruga.sh <dir-extraido> <DISCO.ISO>`: ISO 9660 image of the extracted disc's game area (sectors numbered from LBA 45000, IP.BIN in the system area) that the PSP build reads as the GD-ROM. Needs: genisoimage or mkisofs.
- `probar-ikaruga-ppsspp.sh <EBOOT.PBP> <dir-juego-extraido|-> <segundos> [salida.log]`: runs the EBOOT in PPSSPP on a temporary memory stick with the game data, for the given seconds, and copies `ms0:/PSP/GAME/IKARUGA/ikaruga.log` and PPSSPP's log and output, also when the run fails, and prints PPSSPP's exit code. With game data it needs `PROBAR_DISCO` (the real disc dump, docs/primer-uso.md) and exits 2 without it; `PROBAR_DISCO_ARMADO=1` builds the ISO with `preparar-disco-ikaruga.sh` instead (it differs from the real disc from frame 4). Needs: flatpak `org.ppsspp.PPSSPP`, xvfb-run, genisoimage.
- `test-psp-arranque.sh <EBOOT.PBP> <dir-juego-extraido> [segundos]`: acceptance test: without 1ST_READ.BIN the log has a clear error; with the game the guest frames advance and its PC changes.
- `test-psp-redondeo.sh [dir-parches]`: builds psp/pruebas/redondeo against the patched runtime and checks in PPSSPP that toward-zero truncates 1/3 and nearest rounds it up (FCSR.RM).
- `test-psp-rtc.sh <EBOOT.PBP> <dir-juego-extraido> [segundos]`: `rtc_semilla = 1000` in ikaruga.cfg gives the expected AICA RTC at frame 60.
- `test-psp-igual-pc.sh <EBOOT.PBP> <dir-juego-extraido> [segundos]`: PC <-> PSP oracle: compares `write_hash` at frames 60..600 (no input, RTC seed 1) and fails at the first different frame. Needs `DREAM_RECOMP` with the PC launcher built and `PROBAR_DISCO` with the real disc's HD area (`tools/volcar-area-hd.cpp`).
- `test-psp-salida-suspension.sh <EBOOT.PBP> <dir-juego-extraido>`: HOME exit callback and a simulated suspend/resume (debug keys of ikaruga.cfg); after the resume the hash must still equal PC's.
- `test-psp-carpeta.sh <EBOOT.PBP> <dir-juego-extraido> [segundos]`: the EBOOT runs from `ms0:/PSP/GAME/OTRA_CARPETA/`.
- `test-psp-vmu.sh <EBOOT.PBP> <dir-juego-extraido> [segundos]`: two runs; the first saves VMU.BIN, the second reads it.
- `comparar-geometria.sh <EBOOT.PBP> <dir-juego-extraido> [--cuadro N] [--ventana F0-F1] [--sin-dibujo] [--reusar]`: captures guest frame N (default 2350, start of chapter 1) in PPSSPP through `ikaruga.cfg` and compares the non-black mask (IoU, coverage > 20 %) with the best Flycast image of the window (default `VENTANA_CAP1`). See docs/geometria-psp.md.
- `test-psp-geometria.sh <EBOOT.PBP> <dir-juego-extraido> [--cuadro N] [--reusar]`: acceptance tests (a) geometry and IoU >= 0.6 against Flycast, (b) negative without drawing (one colour, IoU < 0.6).
- `comparar-titulo.sh <EBOOT.PBP> <dir-juego-extraido> [--cuadro N] [--ventana F0-F1] [--sin-texturas] [--region NAME:x0,y0,x1,y1]... [--exigir RULE]... [--iou] [--cfg LINE]...`: runs the EBOOT in PPSSPP up to guest frame N (default 1243, with `start@700`), takes its own capture and compares it with the Flycast series through `comparar-flycast.sh --captura`; never launches the PC. `test-psp-titulo.sh <EBOOT.PBP> <dir-juego-extraido> [--todas]` runs the acceptance tests (a)(b)(c), and (d) with `--todas`. See docs/titulo-psp.md.

- `test-psp-video.sh <EBOOT.PBP> <dir-juego-extraido> [--reusar] [--solo a|b|c]`: acceptance of the user tile clip (side columns SSIM at frame 2350) and fog (mode buttons at frame 1750), each against Flycast by region with its negative (`recorte=0`, `niebla=0`), plus the title. See docs/video-psp.md.
- `test-psp-texturas-juego.sh <EBOOT.PBP> <dir-juego-extraido> [--cuadro N] [--reusar]`: the texture cache at chapter 1 frame N (default 2350): (a) refuses no request in the captured render, (b) PSNR >= 20 dB against Flycast, (c) with the old 2048 KB cap it does refuse. See docs/velocidad-psp.md.
- `escenas-flycast.sh`: sourced by the image tests; the Flycast series windows and the PSP guest frame of each scene.
- `contar-poligonos.cpp`: by-hand tool that counts the polygons of a PC `--dump-ta` stream with the submodule's `DisplayList` (no test uses it).
- `test-gitignore.sh`: game data, captures, memory cards and the cfg/log next to the EBOOT are ignored wherever they land; no tracked file matches `.gitignore`. Needs no game files.
- `capturar-flycast.sh <disco.chd> [--pulsar P] [--segundos S] [--fps F] [--salida DIR]`: runs Ikaruga in Flycast (flatpak, stable) on Xvfb with presses sent as X keys (xdotool) and records the screen (ffmpeg x11grab) as PNGs, also scaled to 480x272. See docs/referencia-flycast.md.
- `comparar-flycast.sh --captura <captura-N.raw|png> --ventana F0-F1 [--serie DIR] [--region NAME:x0,y0,x1,y1]... [--exigir RULE]... [--iou] [--sin-borde]`: the one comparison tool of the image tests: PSNR/SSIM (whole screen, left/centre/right columns, named regions) and optionally the IoU of the non-black masks between a PSP capture and the best-SSIM image of a window of the Flycast series; exit 0/1 by the `--exigir` rules, 3 when the scene is not in the window. The series (`build/flycast/ref/p480`, gitignored) is recorded with `capturar-flycast.sh` when missing; the windows are in `escenas-flycast.sh`. Second mode: `comparar-flycast.sh <serie-flycast/p480> <serie-psp> --escena NAME:F0-F1:P0-P1... [--contra A:B]...`, scene by scene between two series (PSP series from probar-ikaruga-ppsspp.sh with `PROBAR_GRABAR=DIR`). See docs/referencia-flycast.md.
- `test-psp-igual-pc-double.sh [--contraprueba] <EBOOT.PBP> <dir-juego-extraido> [segundos]`: EBOOT `DREAM_FPU_DOUBLE=1` vs PC double con las pulsaciones del capítulo 1, `write_hash` igual en 60…2600 (y en cada cuadro); `--contraprueba` exige la divergencia en 1983 (EBOOT con `DREAM_SOFT_DAZ=0`). docs/correctitud-psp.md.
- `bateria.sh <EBOOT.PBP> <dir-juego-extraido> [--double EBOOT-double.PBP] [--sin-velocidad] [--solo a,b]`: runs every test above in order (video only its (a) and (b): its (c) is the title's (a)), the double-build oracle with `--double`, and `medir-velocidad.sh --solo 2600`; one line per test and `N/M ok`, fails if one fails. Needs `PROBAR_DISCO`; outputs in `build/psp/evidencia/bateria/`.
- `medir-velocidad.sh <EBOOT.PBP> <dir-juego-extraido> [--veces N] [--salida DIR] [--solo 2600|1243]`: speed in PPSSPP with its 60 Hz limiter at chapter 1 frame 2600 and the title; exits 1 if a run gave no speed.
- `medir-memoria.sh <EBOOT.PBP> <dir-juego-extraido> [--salida DIR] [--texturas-kb N] [--solo titulo|2350|2600]`: memory counter (`memoria=1`) in PPSSPP at the title and chapter 1 frames 2350 and 2600; prints the `mem:`/`memory:` lines of each run (`docs/memoria-psp.md`). Needs `PROBAR_DISCO`.
- `armar-docs.sh [--salida archivo.pdf] [--con-mediciones]`: one PDF with table of contents from the docs listed in the tables of `docs/README.md`, in that order (default `build/docs/ikaruga-psp.pdf`); `--con-mediciones` appends the `docs/mediciones/` photos. Needs: `pandoc`, `xelatex` (`texlive-xetex`, `texlive-latexextra`), `ttf-dejavu`, Noto Sans CJK.
- `wayland-socket.sh`: prints the Wayland display for a PC window (`$WAYLAND_DISPLAY`, else the first `wayland-N` socket in `$XDG_RUNTIME_DIR`); exits 1 if there is none. No script uses it now (the image tests do not open the PC window); kept for launching `ikaruga_boot --window` by hand.
